
# AR FOUNDATION ACTIVITY 1 - Micuarto y miquinto (Equipo TOmaka)
Primer proyecto de VR que tiene como objetivo crear una aplicación de Realidad Augmentada (AR) mediante Unity y el AR Foundation package. <br>
Se desglosa en 3 ejercicios : 
<ul>
  <li>plane detection</li>
  <li>image tracking</li>
  <li>implementar una función adicional AR Foundation (Point Cloud)</li>
</ul>

## Installation
Descarga la APK de la release“micuarto.y.miquinto.apk”
Ejecuta la APK y ¡a disfrutar!


## Usage

¡Disfruta de las partículas dispersas por el escenario! Escanea a Gato Risotadas y Paredes Simpson para que aparezca una bola sorpresa. Muévete por el escenario y visualiza las paredes virtuales que detecta. ¡Añade en ellas los diferentes objetos que te interesen solo clicando a la localización preferida! En el icono del cubo puedes mirar distintos objetos que añadir al mundo virtual.
